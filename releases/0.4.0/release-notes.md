# 成长账本 0.4.0

学习、生活与奖励按本人确认的新规则运行。旧余额数值保留，历史流水继续可读，不重算历史。

- 界面货币为U币；商品由本人设置，100元对应100U币，支持到分的价格。
- 所有学习共用有效时长，每累计10分钟1U币；毫秒零头跨次、跨天和重开保留。没有完成奖励、计划/章节/笔记门槛或每日上限。
- 在账本“今日”开始、暂停和结束。离开今日页、应用进入后台或锁屏会自动暂停。人离开但手机仍停在计时页时，请手动暂停。异常关闭只保留最近30秒检查点之前已保存的时长，不补算离开时间。
- 首次在“设置→滴答连接”分别指定学习计时、生活行动清单；按实际ID保存。只读取这两张清单的任务内容，其他位置不参与。绑定时读取可选清单的名称和ID，不读取其他清单任务。
- 生活行动先在设置确认固定U币，以后日常一键完成；未确认分值不发币。普通任务手动登记再同步只计一次，重复任务无法可靠辨认某次完成时不自动发币，可在账本按实际完成登记。
- 官方滴答有专注记录接口，但发现记录需全账户查询且无清单ID过滤；任务上的时长汇总缺少逐段身份。本版为守住指定范围使用账本计时，不自动导入滴答专注，不把标题、预计时长或勾选完成当作实际时间。
- 旧商品与旧订单保留在高级设置，原值可查看，旧订单沿原规则处理；新商品采用新关系。旧清单默认8分不再用于新收入。旧备份可读；新版备份含新命令，旧应用无法读取。

更新：先在设置导出完整备份，然后在“设置→软件更新→检查更新”下载并按系统提示覆盖安装，不卸载、不清数据。0.3.1及以后使用同一GitHub更新渠道。如果手机仍是0.3.0或更旧、检查更新403，旧包写死的失效地址不能由服务器修复，可直接覆盖安装0.4.0这一次，之后继续在应用内更新。

电脑完成188项自动化测试（106核心＋82安卓模拟）、旧0.3.1核心实际生成的格式4合成备份迁移、新版备份重放、lint、正式构建与原签名检查。真机系统安装、vivo后台/锁屏行为、真实账户权限及完整旧账保留、系统导出恢复仍需本人手机确认；合成测试不代表这些已通过。
